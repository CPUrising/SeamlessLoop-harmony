## 如何获取采样点数值

任选其一：

1. **给我 `.db` 文件**（推荐）：WPF 端的 SQLite 数据库，路径通常在 `%LOCALAPPDATA%` 下。我会自己查 `Tracks` 与 `LoopPoints` 表。
2. **从 WPF 界面读**：打开该曲目，记录界面显示的 LoopStart / LoopEnd（注意单位是采样点，不是秒）。
