## 2. A/B 对

A/B 对视为一首曲目：A 播完无缝接 B，之后循环 B。**数据库只存 A 的记录，B 不入表**，B 由同目录同扩展名的 `_b` / `_B` / `_end` 后缀推导。

| A 文件 | B 文件 | 格式 | 采样率 | 声道 | A 帧数 | B 帧数 | A+B | DB TotalSamples | LoopStart | LoopEnd |
|---|---|---|---|---|---|---|---|---|---|---|
| `bgm03_2_a.ogg` | `bgm03_2_b.ogg` | OGG Vorbis | 48000 | 2 | 460798 | 3916798 | 4377596 | 4377596 | 460798 | 4377596 |

**坐标基准**：`LoopStart` / `LoopEnd` / `TotalSamples` 全部在 **A+B 拼接后的虚拟时间轴**上表示。

- `LoopStart = 460798 = A 帧数` → 对应 B 的第 0 帧
- `LoopEnd = 4377596 = A+B` → 对应 B 的末尾
- 即循环区间恰好是整个 B

**边界连续性实测**（`bgm03_2`）：

| 指标 | 值 | 判定 |
|---|---|---|
| A 末帧 → B 首帧 突变 | 31.50 | 比值 0.006（vs B 循环体最大 5490.5） |
| B 末帧 → B 首帧（循环点）突变 | 923.50 | 比值 0.168 |
| B 循环体最大相邻差 | 5490.50 | — |
| B 循环体 RMS | 3077.60 | — |

两个边界均远小于循环体内部正常波动，素材质量合格。

## 3. 后缀匹配规则

| 组 | A 侧 | B 侧 |
|---|---|---|
| 小写 | `_a` | `_b` |
| 大写 | `_A` | `_B` |
| 语义 | `_start` | `_end` |

- 大小写不敏感
- 仅同目录、同扩展名
- 输入 A 侧或 B 侧均可，统一归一化为「A 侧 + B 侧」
- 找不到配对时退化为单文件播放
